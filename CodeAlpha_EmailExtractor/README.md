# Email Address Extractor

## CodeAlpha Python Programming Internship

This project was developed as part of the CodeAlpha Python Programming Internship.

## Project Description

The Email Address Extractor is a Python automation script that automatically
extracts email addresses from a text file and saves them into a separate file.

This eliminates the need to manually search through large amounts of text for
email addresses.

## Features

- Reads text from an input file
- Automatically detects email addresses
- Uses Regular Expressions (Regex)
- Removes duplicate email addresses
- Displays extracted emails
- Saves extracted emails to a separate text file
- Handles missing input files

## Technologies and Concepts Used

- Python
- Regular Expressions (re)
- File Handling
- Functions
- Lists
- Loops
- Exception Handling

## Files

- `email_extractor.py` - Main Python program
- `input.txt` - Input text containing email addresses
- `emails.txt` - Automatically generated output file

## How to Run

Make sure Python is installed on your computer.

Open the project directory in the terminal and run:

```bash
python email_extractor.py
```
