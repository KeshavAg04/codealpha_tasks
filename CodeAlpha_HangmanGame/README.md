# Hangman Game

## CodeAlpha Python Programming Internship

This project was developed as part of the **CodeAlpha Python Programming Internship**.

## Project Description

The Hangman Game is a simple text-based Python game in which the computer randomly selects a word and the player tries to guess it one letter at a time.

The player is allowed a maximum of **6 incorrect guesses** before the game ends.

## Features

- Randomly selects a word from a predefined list
- Accepts one-letter guesses from the user
- Displays correctly guessed letters
- Tracks incorrect guesses
- Prevents duplicate guesses
- Validates user input
- Maximum of 6 incorrect guesses
- Displays win or game-over message

## Technologies Used

- Python
- Random module
- Loops
- Conditional statements
- Lists
- Strings
- User input/output

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run:

```bash
python hangman.py
```
